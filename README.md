# Angular Bootstrap App

This is a boilerplate project for an Angular application with Bootstrap and TypeScript.

## Project Structure

```
angular-bootstrap-app
├── src
│   ├── app
│   │   ├── app.component.html
│   │   ├── app.component.scss
│   │   ├── app.component.ts
│   │   ├── app.module.ts
│   │   └── app-routing.module.ts
│   ├── assets
│   │   └── styles
│   │       └── custom-bootstrap.scss
│   ├── environments
│   │   ├── environment.prod.ts
│   │   └── environment.ts
│   ├── index.html
│   ├── main.ts
│   ├── polyfills.ts
│   └── styles.scss
├── angular.json
├── package.json
├── tsconfig.app.json
├── tsconfig.json
├── tsconfig.spec.json
└── README.md
```

## Files

- `src/app/app.component.html`: HTML template for the root component.
- `src/app/app.component.scss`: SCSS styles for the root component.
- `src/app/app.component.ts`: Logic and behavior for the root component.
- `src/app/app.module.ts`: Main module of the Angular application.
- `src/app/app-routing.module.ts`: Routing configuration for the Angular application.
- `src/assets/styles/custom-bootstrap.scss`: Custom styles for Bootstrap.
- `src/environments/environment.prod.ts`: Production environment configuration.
- `src/environments/environment.ts`: Development environment configuration.
- `src/index.html`: Main HTML file for the Angular application.
- `src/main.ts`: Main entry point for the Angular application.
- `src/polyfills.ts`: Polyfills for older browser support.
- `src/styles.scss`: Global styles for the Angular application.
- `angular.json`: Configuration file for the Angular CLI.
- `package.json`: Configuration file for npm.
- `tsconfig.app.json`: TypeScript configuration file for the Angular application.
- `tsconfig.json`: Base TypeScript configuration file for the project.
- `tsconfig.spec.json`: TypeScript configuration file for unit tests.
- `README.md`: Documentation for the project.

## Getting Started

1. Clone the repository.
2. Install the dependencies with `npm install`.
3. Run the development server with `ng serve`.
4. Open the application in your browser at `http://localhost:4200`.
